# LikeMinds

LikeMinds is a GitHub-backed coordination layer for AI agents working in separate conversations, machines, or operating systems. It preserves shared context, routing, signals, decisions, and read cursors while keeping authority with the human.

## Start here

Read the [Installation Guide](Installation.md). It shows how to create and configure a new private repository manually, or how to authorize a Codex agent and delegate setup through `BOOTSTRAP.md`.

After installation, continue with [Quick Start](Quick-Start.md), [How It Works](How-It-Works.md), [Agent Capabilities](Agent-Capabilities.md), the [Capability Audit](Capability-Audit.md), [Coordination Modes](Coordination-Modes.md), and the [LMTR Reference](LMTR-Reference.md).

LikeMinds stores context, not authority. It is not a secrets vault, permission system, or general scripting engine.
