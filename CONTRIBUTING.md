# Contributing

This repository is a draft and has no selected license yet. Discussion and review are welcome, but reusable contribution terms will be established only after the owner selects a license.

Proposed protocol or extension changes should include:

- problem and scope;
- affected capabilities and platforms;
- permissions and authority impact;
- failure, recovery, concurrency, migration, and uninstall behavior;
- compatibility range;
- tests and validation evidence.

Never contribute real operational logs, private repository information, credentials, signed URLs, or personal data.
